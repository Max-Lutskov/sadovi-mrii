# Садові мрії — сайт

Сайт ландшафтної компанії «Садові мрії» (Київ і Київська область, переважно приватні будинки під Києвом).
Мова спілкування з користувачем — українська. Мова сайту — лише українська.

## Навіщо цей сайт
Старий сайт замовника на Readymag (readymag.website/u1984534458/4193863/) зроблено погано, домен sadovi-mrii.com.ua свого часу не продовжили. Замовник пішов, а новий сайт — вітрина, щоб показати, як має бути. 22.10.2026 користувач сам викупив sadovi-mrii.com.ua, сайт переїжджає туди. Клієнти приходять переважно за рекомендацією, тож сайт має швидко переконати людину, якій порадили компанію: роботи, відкриті ціни, телефон.

Проєктне рішення: `docs/superpowers/specs/2026-10-22-sadovi-mrii-site-design.md`.

## Стек
- Nuxt 4 + Vue 3 + TypeScript (strict), Nuxt UI 4 (Tailwind 4), `@nuxtjs/sitemap`, `@nuxtjs/robots`
- Іконки: `@iconify-json/lucide`, `@iconify-json/simple-icons`. Лише в клієнтському бандлі (`icon.serverBundle: false`), бо повні набори на сервері важать ~5 МБ, а безкоштовний Worker — 3 МБ. Іконки самого Nuxt UI перелічені в `icon.clientBundle.icons`
- Скіли проєкту лежать у `.claude/skills/`. Користуйся ними.
- Node 22 (`.nvmrc`)
- Репозиторій: github.com/Max-Lutskov/sadovi-mrii (публічний), гілка `main`

## Дизайн
Варіант A «Від креслення до саду» (вибрав користувач 22.10.2026): світла м'ятна гама, головна анімація — план ділянки малює себе, потім проступає фото саду (`HeroSection.vue`, лише CSS, `prefers-reduced-motion` вимикає). Інших анімацій при завантаженні не додавати, лише реакції на дії.
- Кольори в `main.css`: `leaf-*` (primary), `pine-*` (neutral, `pine-900` — текст), `sprout` (молоде листя), `paper` (фон). Кнопки й посилання — `leaf-700`, щоб білий текст читався
- Шрифти: Geologica (заголовки: світлий 300 + жирний 600 у H1 і назвах секцій), Onest (текст)
- Без ALL-CAPS лейблів, без номерів там, де не послідовність (номери лише в «Як ми працюємо» і етапах робіт)

## Фото
`.jpg` (оригінал для schema/OG) плюс WebP-варіанти 400/600/800/960/1280 для `srcset`. Після додавання чи заміни фото — `npm run images`. Оригінали лише 1280 px.

SEO: schema `HomeAndConstructionBusiness` на всіх сторінках, `Service` з ціною, `BreadcrumbList`, `FAQPage` (`app/utils/schema.ts`). Попит (Ubersuggest, Україна): «ландшафтний дизайн київ» 260/міс, «ландшафтный дизайн киев» 110, «ландшафтний дизайн подвір'я» 590.

`site.url` — https://sadovi-mrii.com.ua, індексація увімкнена (у продакшн-збірці nuxt-site-config ставить її сам).

## Заявки й хостинг
- `server/api/lead.post.ts` шле заявки в Telegram-бот (`NUXT_TELEGRAM_BOT_TOKEN`, `NUXT_TELEGRAM_CHAT_ID`). Без них заявка пишеться в лог. Бот окремий від Процков Буд, підключено 22.10.2026: секрети Worker'а (`wrangler secret`), локально — `.env`. Заявки поки йдуть користувачу (розробнику), не замовнику
- Хостинг: Cloudflare Worker `sadovi-mrii` на власному домені sadovi-mrii.com.ua (`routes` з `custom_domain` у `wrangler.jsonc`, домен має бути зоною в Cloudflare). Адресу workers.dev вимкнено (`workers_dev: false`), щоб не було дубля для Google. www.sadovi-mrii.com.ua переадресовує (301, зі шляхом) окремий Worker `sadovi-mrii-www` у `redirect-www/`, деплой: `npx.cmd wrangler deploy -c redirect-www/wrangler.jsonc`. Деплой вручну: `npm run deploy` (збірка з пресетом `cloudflare_module` + `wrangler deploy`, конфіг `wrangler.jsonc`). Автодеплою з GitHub немає
- На Windows у PowerShell `npx`/`npm` блокує політика скриптів — запускати як `npx.cmd`/`npm.cmd`
