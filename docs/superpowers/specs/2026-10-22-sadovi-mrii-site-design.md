# Садові мрії — сайт з нуля

## Навіщо
Старий сайт на Readymag (2023) зроблено погано, домен sadovi-mrii.com.ua не продовжено. Новий сайт — вітрина, щоб показати замовнику, як має бути. Якщо сподобається, замовник викупить домен і сайт переїде туди. До того — безкоштовний хостинг Cloudflare Workers (`*.workers.dev`).

Компанія робить ландшафтний дизайн приватних будинків під Києвом, клієнти приходять переважно за рекомендацією. Тож сайт має за хвилину переконати людину, якій порадили «Садові мрії»: роботи, відкриті ціни, телефон. Друге завдання — пошук («ландшафтний дизайн київ» 260/міс, «ландшафтный дизайн киев» 110, послуги окремо).

## Цілі
- Перший екран за варіантом A: план ділянки малює себе, крізь нього проступає фото готового саду.
- Повний прайс зі старого сайту (~120 позицій) на окремій сторінці. Ніхто з топу конкурентів цін на сторінці не показує.
- Роботи з підписами, послуги, кроки роботи, FAQ, контакти з формою заявки.
- SEO: окремі сторінки під послуги, schema.org, sitemap, пререндер.

## Не робимо
- Вигаданих відгуків (два зі старого сайту зі стоковими аватарками не переносимо), вигаданих цифр («500 проєктів»), гарантій, яких замовник не давав.
- Стокових фото послуг зі старого сайту.
- Російської версії.

## Структура
- `/` — hero (A), смужка цін, роботи, послуги (9), як працюємо (6 кроків), FAQ, контакти + форма.
- `/tsiny/` — повний прайс за розділами, з пошуком.
- `/proiektuvannia/`, `/rulonnyi-gazon/`, `/avtopoliv/`, `/dohliad-za-sadom/` — сторінки послуг з цінами з прайсу, FAQ, schema `Service`.
- `/polityka-konfidentsiinosti/`.

## Дизайн
Світла м'ятна гама: фон `#f1f6ec`, текст/темний `#1e3b2c`, лінія `#4f8a3c`, молоде листя `#c9e58a`. Шрифти Geologica (заголовки, світлий 300 + жирний 600) і Onest (текст). Одна оркестрована анімація — hero; решта — лише реакція на дії. `prefers-reduced-motion` вимикає анімацію.

## Технічне
Nuxt 4 + Nuxt UI 4, як Процков Буд. Заявки — `server/api/lead.post.ts` у Telegram-бот (без токена — у лог). Фото — `.jpg` + WebP-варіанти (`npm run images`). Деплой — Cloudflare Workers (wrangler), пререндер усіх сторінок.
